# CartaoEstatistica

Bloco de um número: poço pequeno com ícone, valor grande em pixel e rótulo.

- Poço 44 × 44 (`raio-sm`) na cor do jogo; valor `displaySmall`; rótulo `bodyMedium` em `texto-2`.
- Grade de 2 colunas no celular, 3 a partir de 560 px, `espaco-3` de gap.
- Ao abrir a tela, o valor conta de 0 até o número em 600 ms com `curva-padrao` (só números inteiros e porcentagens).
- Estado vazio: esconda o número e use o texto "Sem partidas ainda" em `bodyMedium` `texto-3`. Nunca mostre um traço no lugar do valor.
